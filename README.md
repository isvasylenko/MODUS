# MODUS — Enterprise Architecture Vault

Семантична модель даних для позиції **IT Strategy & Governance Leader @ MODUS X**: ланцюжок створення цінності, capabilities, стратегія, цілі та EA за авторською 7-доменною моделлю Vasylenko.

> Це Obsidian-vault. Відкрийте цю папку як vault в Obsidian: `File → Open Vault → Open folder as vault`.

## Структура

| Папка | Зміст |
|---|---|
| `00-Meta` | Домашня сторінка, семантична модель, конвенції, глосарій, шаблони |
| `10-Strategy` | Візія, стратегічні вектори (VEC), цілі (GOAL) |
| `20-Value-Chain` | Ланцюжок створення цінності — value streams (VS) |
| `30-Capabilities` | Capability Map — бізнес-здатності (CAP) |
| `40-EA-Domains` | Авторська 7-доменна модель EA (D01–D07) + As-Is assessment |
| `50-Governance` | Bodies (ARB/QBR), Principles (AP), ADR, 10 каталогів |
| `60-Organization` | Оргюніти та ролі-власники (ROLE) — **без персональних даних** |
| `90-Research` | Сирі дослідження й джерела |

## Семантичний ланцюг

```
Vision → Vectors → Goals → Value Streams → Capabilities → EA Domains
                                                ↑
                            Governance (ARB · ADR · Principles · Catalogs)
                                                ↑
                                    Organization (Units · Roles)
```
