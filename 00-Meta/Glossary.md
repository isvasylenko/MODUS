# Glossary

| Термін | Значення |
|---|---|
| **EA** | Enterprise Architecture — корпоративна архітектура |
| **ARB** | Architecture Review Board — операційний орган архітектурних рішень |
| **QBR** | Quarterly Business Review — квартальний огляд стратегії, портфеля, KPI та ризиків |
| **ADR** | Architecture Decision Record — зафіксоване архітектурне рішення |
| **Capability** | Бізнес-здатність: ЩО компанія вміє робити, незалежно від того ЯК і ХТО |
| **Value Stream** | Наскрізний потік створення цінності: від тригера до результату для клієнта |
| **MOC** | Map of Content — навігаційна нотатка-вузол в Obsidian |
| **QUANTUM** | Програма AI-трансформації ДТЕК: 15 проєктів у 2026 |
| **DEEP** | Власна мобільна платформа MODUS X «компанія в смартфоні»; перший модуль — DEEP HR |
| **«Компанія у смартфоні»** | Кейс для ДТЕК: 25 000+ активних користувачів щомісяця, 100% охоплення персоналу |
| **NIS2** | EU директива з кібербезпеки критичної інфраструктури |
| **DORA** | Digital Operational Resilience Act — EU регламент операційної стійкості (фінсектор) |
| **Waiver** | Тимчасовий виняток із принципу/стандарту з терміном дії |
| **Maturity** | Зрілість 1–5, див. [[Conventions]] |
| **7-доменна модель** | Авторська модель EA: Strategy · Business · Data & AI · Application · Technology · Security · People & Culture |
