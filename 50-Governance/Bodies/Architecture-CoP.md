# Architecture CoP · Community of Practice

> Спільнота архітекторів і tech leads. Створює культуру, без якої governance = бюрократія. Прямий інструмент для домену [[D07-People-Culture]].

## Формат

- Щомісячна зустріч: розбір ADR, обмін патернами, гостьові теми
- Канал знань: патерни, референс-архітектури, post-mortem'и
- Онбординг нових tech leads у governance-практики

## Навіщо

- EA skills framework — вирощується тут ([[D07-People-Culture]] 🔴)
- Architecture NPS — вимірюється тут (опитування учасників)
- ADR пишуть не "згори" — культура рішень народжується в спільноті
